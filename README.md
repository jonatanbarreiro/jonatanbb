# jonatanbb.xyz

My personal site: an index of the things I make, each a node wired to the bb signet.
It began as a CV page built from scratch in the open; that site, its making-of and its
whole chain of iterations now live in [`cvsite/`](cvsite/), and it is served at
jonatanbb.xyz/cv/.

The source is `index/`; `gallery/` shows how it looked after each iteration,
`prompts/` keeps every session's log verbatim, and [milestones.md](milestones.md)
tracks where jonatanbb.xyz is headed, version by version.
